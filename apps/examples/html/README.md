# argus-table starter: plain JavaScript

One `<argus-table>` with 10,000 generated orders: a search box (`quickFilter`), the column menu from `@argus-table/header-menu` (sort, filter, pin, hide), row selection with checkboxes, a pinned column and a status cell built as a DOM node.

```bash
npm install
npm run dev
```
