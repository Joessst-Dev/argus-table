# @argus-table/docs

The docs site: Astro with Starlight, every feature in plain HTML, React, Vue and Angular. Not deployed yet: CI builds it on every pull request and uploads it as the `docs-site` artifact. See `docs/superpowers/specs/2026-11-16-docs-site-design.md`.

```bash
pnpm nx run docs:build     # apps/docs/dist
pnpm nx run docs:preview   # http://localhost:4321/argus-table/
```
