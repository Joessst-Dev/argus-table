## Install

```bash
npm i argus-table @argus-table/themes
```

With a framework, install its wrapper too. It brings typed props and events, and renders your framework's components in cells:

```bash
npm i @argus-table/react   # or @argus-table/vue, @argus-table/angular
```

Or, without a build step, from a CDN, with every dependency bundled:

```html
<script
  type="module"
  src="https://cdn.jsdelivr.net/npm/argus-table/dist/cdn/argus-table.js"
></script>
```

## A first table

Three columns of orders: the order number pinned to the start, a sortable customer name read from a nested object (`customer.name`), and a sortable total. Click a header to sort, and a row to select it.

Three things every table needs:

- **A bounded height.** The table virtualizes its rows, so it needs a height to fill: `block-size` (or `height`) on the element, or a parent that bounds it. Without one it's 400 px tall.
- **An accessible name.** Give it `aria-label` or `aria-labelledby`. It has `role="grid"`, and screen readers announce the name.
- **Columns and data as properties,** not attributes: they hold objects and functions. The wrappers set them for you. `getRowId` gives each row a stable id, which selection, saved state and a `dataSource` rely on.

## Themes

The examples on this site use the default theme. Load one theme on your page:

```js
import '@argus-table/themes/default.css';
```

There are five, each one CSS file: Default, Material-inspired, Fluent-inspired, Bootstrap-inspired and Minimal. See [Themes](/argus-table/themes/), or make your own in the [theme creator](/argus-table/themes/creator/).
