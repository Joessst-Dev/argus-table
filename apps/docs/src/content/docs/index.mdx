---
title: argus-table
description: A virtualized data table web component, with every feature shown in plain HTML, React, Vue and Angular.
---

argus-table is a data table web component built with Lit: virtualized rows and columns, sorting, filtering, selection, pinned columns and rows, resizing, reordering, infinite loading and more. It works in any framework or none, with wrappers for React, Vue and Angular.

Every feature page shows the feature running in all four, next to the code that runs it.
