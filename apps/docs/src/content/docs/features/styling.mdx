Three ways in, from the outside: `::part()` rules for the table's structure, `--argus-*` tokens for its colours and sizes, and your own CSS for what you put in its cells. The examples' rules are in `styles.css`, shown with each flavour; every example scopes its rules with a class on its table.

## Parts

`::part()` styles the table's structure from outside its shadow DOM. State is part of the name (`row-odd`, `header-cell-sorted`, `cell-pinned-edge`), because parts can't be combined with attribute selectors. Pseudo-classes work: `::part(row):hover`. Click a sortable header (Customer, Total) to see `header-cell-sorted`.

## Your CSS in cells

Cell and header content is rendered into the table's light DOM and slotted into the cells, so the page's own CSS, utility classes and components work inside cells. Here `.badge` is a plain class from the page's stylesheet, and the Actions column has a header only screen readers see.

## Tokens

Tokens are CSS custom properties, so they pass into the shadow DOM: set them on the table, on a parent, or in a theme. Striped rows, a hover colour and taller rows, from tokens alone:

  <VueStriped slot="vue" client:visible />
  <StripedComponent slot="angular" client:visible />
</FlavourTabs>

A border around the table and rounded corners: `--argus-border` and `--argus-border-radius`.
