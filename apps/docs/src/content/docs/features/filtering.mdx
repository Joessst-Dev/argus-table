`quickFilter` keeps the rows that contain each word of a text in one of their shown columns, ignoring case: wire it to your own search box. Here 100,000 orders are searched as you type ("oslo 777", say). The table announces the number of rows left to screen readers.

## Column filters

`columnFilters` holds a filter per column id: `text` (contains, equals, starts with, empty), `number` and `date` (comparisons and ranges), or `set` (one of a list of values). It's a plain object, so it saves as JSON. Here a form sets it; the column menu of `@argus-table/header-menu` lets users set filters on columns with a `filter` kind, and fires `argus-column-filters-change`. Filtered headers get the `header-cell-filtered` part and a funnel mark. A column's `filterFn` replaces the built-in test.

## With a data source

With a [`dataSource`](../infinite-loading/), the table doesn't filter: `columnFilters` and `quickFilter` go to `getRows({ start, end, sorting, filters, quickFilter, signal })`, and a change reloads from the top. A `set` filter there lists the column's `filterOptions`, since the table can't see every value. This pretend server filters by status and searches the customer; the last request it got is shown below the table.
