Columns with `sortable: true` sort with a click on their header, or with Enter or Space on a focused header: ascending, then descending, then unsorted. `sorting` holds the order as `{ id, desc }[]`. Once you set it, the table is controlled: a click only proposes the new order in `argus-sorting-change`, and your code applies it, as each example below does.

A sorted header shows the direction with a chevron and in `aria-sort`; its cells get the `cell-sorted` part, so themes can mark the column.
