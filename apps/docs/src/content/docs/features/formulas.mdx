`@argus-table/formulas` is a plugin: `plugins: [formulas()]`. A column with a `formula` computes its value per row from other columns, named in brackets by id or by header: here Total, Gross, Stock and Month. A formula can use another formula column (Gross uses Total), and a formula column sorts, resizes and moves like any other. Numbers and dates align to the end, and the header gets an `ƒx` mark. Create the plugin once: a new instance compiles every formula again.

## Whole columns

`[[name]]` is a whole column: its values in every row the filters keep, while `[name]` is the row's own value. Share % divides by `SUM([[Total]])`, Orders of product counts with `COUNTIF`, Rank ranks with `RANK`, and Best seller looks up the product of the largest total with `INDEX` and `MATCH`. Filter Product from its column menu: every total follows. A filter on Share % itself hides rows but leaves its totals alone. List `formulas()` before `headerMenu()`, so the menu button sits after the `ƒx` mark.

## Errors

Errors are cell values, never crashes: they pass through the rest of the formula, explain themselves in a tooltip, and sort last. `IFERROR` replaces them, and `--argus-formula-error-fg` colours them.

## Functions of your own

Functions go in the `functions` option: `formulas({ functions: { VAT: { fn: (net) => Number(net) * 0.19, args: [1, 1] } } })`, where `args` is the least and most number of arguments. Names are case-insensitive.

## Editing formulas

With `formulas({ editing: 'edit' })` and the column menu, users add, edit, rename and delete formula columns. The editor colours the formula, suggests columns after `[` and functions by name, shows the arguments of the function the cursor is in, and previews the first five rows. It loads on first use. The table doesn't change its columns itself: the plugin fires `argus-formula-column-add`, `-change` and `-remove`, and your code sets `columns` to `event.detail.columns`.
