`@argus-table/header-menu` is a plugin: `plugins: [headerMenu()]`. Each column gets a button in its header, which opens a menu to sort the column, clear its sort, pin it, fit its width to its content, or hide it; every menu lists the hidden columns, to show them again. A right-click on a header opens it too, and so do Alt+ArrowDown, the context menu key and Shift+F10 on a focused header. Arrow keys, Home and End move through it, Enter or Space runs an item, and Escape or Tab closes it; focus goes back to the header.

Create the plugin once: a new instance reconnects and closes an open menu. `headerMenu({ sort: false, fitWidth: false, pin: false, hide: false, filter: false })` turns items off, and `pinnable: false` or `hideable: false` leave a column out.

The menu is a native popover in the top layer, so a short table or a pinned column never clips it. It follows the table's theme tokens and has its own: `--argus-menu-bg`, `--argus-menu-fg`, `--argus-menu-shadow` and `--argus-menu-item-active-bg`.

## Controlled state

The menu changes the table the way a user would: through `sorting`, `columnPinning`, `columnVisibility` and `columnFilters`. With one of them controlled, the menu only proposes, through the property's change event, and your code decides. Here `sorting` is bound one way and never applied.

## Headers with content

A header that is framework content still gets its name in the menu ("Show Customer") and in announcements. A `header` function returns plain text when its context asks for it (`({ text }) => …`); a Vue `#header-<id>` slot or an Angular `argusHeader` template takes the name from the definition's `header` text. Without either, the column is named by its id.

## Filters

Columns with a `filter` kind get Filter… in their menu: a small form for a `text` condition, a `number` or `date` comparison or range, or the values of a `set` (searchable, listed from the rows the other filters leave). Typed values apply as typing pauses, Enter or Done closes the form, Escape closes it as it is, and Clear (or Clear filter in the menu) removes the column's filter. The form sets [`columnFilters`](../filtering/).
