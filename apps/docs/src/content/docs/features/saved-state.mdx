`getState()` returns what users changed as one object of plain JSON: sort order, column widths, order, pins, hidden columns, filters, selection, `quickFilter` and the scroll position. `setState(state)` puts it back. Sort, resize, move or hide columns (the column menu of `@argus-table/header-menu` pins, hides and filters them), scroll, then Save: the layout goes to `localStorage` and comes back with Restore, after a reload too.

`setState()` changes only the keys it's given, leaves properties you control alone, and fires no events. It resolves once the state is applied, scroll position included. A state saved by another version of the format is ignored.
