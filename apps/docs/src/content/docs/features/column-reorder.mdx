Drag a header to move its column: a line marks where it will land, and Escape cancels. Or focus a header and press Alt+Shift+Arrow to move it one place; screen readers hear where it went. A column with `reorderable: false` (# here) can't be picked up, though other columns can move past it. Pinned columns move only among themselves, and scrolling columns among theirs: a move never pins or unpins a column.

## Saving the order

`columnOrder` holds the column ids in the order the table shows them. Set it and the table is controlled: a move proposes the new order in `argus-column-order-change`, and your code applies it, here saving it to `localStorage` too.
