# React

`@argus-table/react` wraps `<argus-table>`, `<argus-column>` and `<argus-column-group>` as React components, with typed props and typed events. The row type is inferred from `data`.

```bash
npm i @argus-table/react @argus-table/themes
```

## A table

```tsx
import { ArgusTable, type ColumnDef } from '@argus-table/react';
import '@argus-table/themes/default.css';

const columns: ColumnDef<Order>[] = [
  { id: 'id', header: 'Order', accessor: 'id', width: 90, pin: 'start' },
  { id: 'customer', header: 'Customer', accessor: 'customer.name', width: { flex: 1 } },
  { id: 'total', header: 'Total', accessor: 'total', align: 'end', sortable: true },
];

export function Orders({ orders }: { orders: Order[] }) {
  return (
    <ArgusTable
      aria-label="Orders"
      style={{ height: 400 }}
      columns={columns}
      data={orders}
      onRowClick={(e) => open(e.detail.row)}
    />
  );
}
```

Props set the element's properties. Each `argus-*` event is an `on*` prop that gets the element's `CustomEvent`:

| Event                            | Prop                       |
| -------------------------------- | -------------------------- |
| `argus-sorting-change`           | `onSortingChange`          |
| `argus-column-sizing-change`     | `onColumnSizingChange`     |
| `argus-column-order-change`      | `onColumnOrderChange`      |
| `argus-column-pinning-change`    | `onColumnPinningChange`    |
| `argus-column-visibility-change` | `onColumnVisibilityChange` |
| `argus-column-filters-change`    | `onColumnFiltersChange`    |
| `argus-selection-change`         | `onSelectionChange`        |
| `argus-cell-click`               | `onCellClick`              |
| `argus-row-click`                | `onRowClick`               |
| `argus-range-change`             | `onRangeChange`            |
| `argus-load-error`               | `onLoadError`              |

A column's `cell` and `header` can return JSX, as well as a string, a number, a DOM node or a Lit template. The JSX renders through portals in your component tree (it sees your providers), and pooled cells update their components with the next row's props as the table scrolls rather than remounting them:

```tsx
const columns: ReactColumnDef<Order>[] = [
  { id: 'status', header: <b>Status</b>, cell: (o) => <StatusBadge status={o.status} /> },
];
```

## Controlled sorting

Leave `sorting` out and the table sorts by itself. Pass it, and a header click only proposes the new order:

```tsx
const [sorting, setSorting] = useState<SortState>([]);

<ArgusTable
  columns={columns}
  data={orders}
  sorting={sorting}
  onSortingChange={(e) => setSorting(e.detail.sorting)}
/>;
```

Every controllable property works the same way: `columnSizing` with `onColumnSizingChange` (`e.detail.columnSizing`), `columnOrder` with `onColumnOrderChange`, `columnPinning`, `columnVisibility`, `columnFilters` and `selection` with `onSelectionChange` (`e.detail.selection`). The value is always in `e.detail` under the property's name.

## Methods

```tsx
const table = useRef<ArgusTableElement<Order>>(null);

<ArgusTable ref={table} columns={columns} data={orders} />;

await table.current?.scrollToRow(0);

// Save and restore a user's layout (sorting, widths, order, filters, scroll...).
const saved = table.current?.getState();
if (saved) await table.current?.setState(saved);
```

## Columns from a loop

```tsx
<ArgusTable<Order> data={orders}>
  {visible.map((c) => (
    <ArgusColumn key={c.id} columnId={c.id} header={c.label} accessor={c.id} sortable />
  ))}
</ArgusTable>
```
