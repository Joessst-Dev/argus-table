# Vue

`@argus-table/vue` wraps `<argus-table>`, `<argus-column>` and `<argus-column-group>` as Vue components, with typed props, typed events and `v-model`. The row type is inferred from `data`, and vue-tsc checks your templates against it.

```bash
npm i @argus-table/vue @argus-table/themes
```

## A table

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { ArgusTable, type ColumnDef, type SortState } from '@argus-table/vue';
import '@argus-table/themes/default.css';

const props = defineProps<{ orders: Order[] }>();
const sorting = ref<SortState>([]);

const columns: ColumnDef<Order>[] = [
  { id: 'id', header: 'Order', accessor: 'id', width: 90, pin: 'start' },
  { id: 'customer', header: 'Customer', accessor: 'customer.name', width: { flex: 1 } },
  { id: 'total', header: 'Total', accessor: 'total', align: 'end', sortable: true },
];
</script>

<template>
  <ArgusTable
    v-model:sorting="sorting"
    aria-label="Orders"
    style="height: 400px"
    :columns="columns"
    :data="props.orders"
    @row-click="(e) => open(e.detail.row)"
  />
</template>
```

Props set the element's properties. Each `argus-*` event is emitted without its prefix, with the element's `CustomEvent`:

| Event                  | Vue event        |
| ---------------------- | ---------------- |
| `argus-sort-change`    | `sort-change`    |
| `argus-column-resize`  | `column-resize`  |
| `argus-column-reorder` | `column-reorder` |
| `argus-cell-click`     | `cell-click`     |
| `argus-row-click`      | `row-click`      |
| `argus-range-change`   | `range-change`   |
| `argus-load-error`     | `load-error`     |
| `argus-row-select`     | `row-select`     |

`v-model:sorting`, `v-model:column-sizing`, `v-model:column-order` and `v-model:selection` bind the four properties the table can change. Unbound, the table keeps that state itself.

Cells and headers take Vue content: a `#cell-<column id>` slot gets the row (`{ row, value, rowId, index }`, typed from `data`), `#header-<column id>` gives a header, and `#group-<group id>` a column group's header (`{ groupId }`). `cell` and `header` in `columns` can also return VNodes from `h()`. Pooled cells update their components with the next row's props as the table scrolls, rather than remounting them:

```vue
<ArgusTable :columns="columns" :data="orders">
  <template #cell-status="{ value }"><StatusBadge :status="value" /></template>
</ArgusTable>
```

## Methods

```vue
<script setup lang="ts">
import type { TableState } from '@argus-table/vue';

const table = useTemplateRef('table');
const top = () => table.value?.scrollToRow(0);
// Save and restore a user's layout (sorting, widths, order, filters, scroll...).
const save = () => table.value?.getState();
const restore = (state: TableState) => table.value?.setState(state);
</script>

<template>
  <ArgusTable ref="table" :columns="columns" :data="orders" />
</template>
```

## Columns from a loop

```vue
<ArgusTable :data="orders">
  <ArgusColumn v-for="c in visible" :key="c.id" :column-id="c.id" :header="c.label" :accessor="c.id" sortable />
</ArgusTable>
```

## Render functions

`h()` can't infer the row type, so give it: `h(ArgusTable<Order>, { columns, data, onRowClick })`.
