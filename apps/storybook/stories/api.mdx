## Events

| Event                  | Constant         | `detail`                            | Fires                                                                                                                                                                                    |
| ---------------------- | ---------------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `argus-range-change`   | `RANGE_CHANGE`   | `{ start, end }`                    | After an update that changed the visible rows                                                                                                                                            |
| `argus-sort-change`    | `SORT_CHANGE`    | `{ sorting }`                       | After the sort changed (uncontrolled), or with the proposed sort (controlled)                                                                                                            |
| `argus-column-resize`  | `COLUMN_RESIZE`  | `{ columnId, width, sizing }`       | After a resize (uncontrolled), or with the proposed widths (controlled). A drag, Alt+Arrow, a double-click on the handle or `autosizeColumns()` (one per column)                         |
| `argus-column-reorder` | `COLUMN_REORDER` | `{ columnId, order }`               | After a column moved (uncontrolled), or with the proposed order (controlled). A header drag (on drop) or Alt+Shift+Arrow on a focused header                                             |
| `argus-cell-click`     | `CELL_CLICK`     | `{ row, columnId, value, pinned? }` | On a click in a body or pinned-row cell; `pinned` is set for a pinned row                                                                                                                |
| `argus-row-click`      | `ROW_CLICK`      | `{ row, rowId, index, pinned? }`    | On a click in a body or pinned row, after `argus-cell-click`                                                                                                                             |
| `argus-load-error`     | `LOAD_ERROR`     | `{ error, start, end }`             | After a `dataSource` page failed to load (`end` exclusive)                                                                                                                               |
| `argus-row-select`     | `ROW_SELECT`     | `{ selection }`                     | After the selected rows changed (uncontrolled), or with the proposed ids (controlled). A click on a row, Space, Shift+Arrow, Shift+PageUp/PageDown or Ctrl/Cmd+A, with a `selectionMode` |

## Controlled and uncontrolled state

`sorting`, `columnSizing`, `columnOrder`, `columnPinning`, `columnVisibility`, `columnFilters` and `selection` work either way. Leave them unset and the table keeps its own state, then fires the event. Set them and the table only proposes: it fires the event with the new state and waits for you to set the property. Set them back to `undefined` to hand control back to the table.

## Saving a layout

`getState()` returns that state, plus `quickFilter` and the scroll position, as one object of plain JSON; `setState(state)` restores it (see Features/Saved state). It applies only the keys it's given, leaves the ones you control alone, keeps the others uncontrolled and fires no events.

```js
const KEY = 'orders-table';
await table.setState(JSON.parse(localStorage.getItem(KEY) ?? '{}'));
addEventListener('pagehide', () => {
  localStorage.setItem(KEY, JSON.stringify(table.getState()));
});
```

## Plugins

`plugins` takes add-ons, such as the column menu from `@argus-table/header-menu` (see Add-ons/Header menu) and formula columns from `@argus-table/formulas` (see Add-ons/Formulas: a column with `formula: '[price] * [qty]'` computes its value per row, and with `editing: 'edit'` users add and edit them from the column menu). A plugin is an object with a `name` and any of these hooks:

```ts
import type { ArgusPlugin } from 'argus-table';

const plugin: ArgusPlugin<Order> = {
  name: 'my-plugin',
  // While the table is connected; return a cleanup.
  connect(host) {
    return () => {};
  },
  // Change the column definitions before the table reads them.
  columns: (defs, host) => [
    ...defs,
    { id: 'gross', header: 'Gross', accessor: (o) => o.total * 1.19 },
  ],
  // A key on a focused header or cell, before the table: return true to claim it.
  keydown: (event, target, host) => false,
};
table.plugins = [plugin];
```

The `host` reads resolved columns (`column(id)`), finds the header or cell of an event (`cellOf(event)`), sorts (`setSort(id, 'asc' | 'desc' | null)`, under the `sorting` rules), focuses a header (`focusHeader(id)`), announces to screen readers (`announce(message)`), runs the `columns` hooks again (`invalidateColumns()`), re-renders (`requestUpdate()`) and reads body rows in the current order (`row(index)`, optional). The table itself is `host.element`. Plugins run in array order; one that throws is reported in the console and skipped.
